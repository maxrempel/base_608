# Agent F: Repository Mining Wave 2 — Long-Read Family-Labeled Submissions

**Date:** 2026-08-06
**Agent:** F (repository metadata mining)
**Repositories searched:** ENA portal API, NCBI E-utilities (SRA esearch/efetch, Assembly esearch/esummary, Datasets API), DDBJ DRA (API returned 403 Forbidden), NGDC/CNCB GSA-Human (no public JSON API; web interface returned 404 for search endpoints), GWH (not separately queried after GSA-Human failure)

## Method

Queried ENA portal API with field-qualified study searches combining family/trio/pedigree/three-generation terms with PacBio/nanopore/long-read/HiFi/ONT/Revio/Sequel terms, restricted to human (tax_tree(9606)). Queried NCBI SRA via esearch with equivalent term combinations. Checked NCBI Assembly and Datasets APIs. Attempted DDBJ DRA search API (403 Forbidden). Attempted GSA-Human JSON API (404 — no public REST API exists). For each candidate, verified platform, sample composition, and open-vs-controlled access status.

## Conclusion

Repository mining of ENA and NCBI SRA did not identify any new OPEN ACCESS whole-genome long-read family-labeled submissions with ≥3 family members beyond the already-known 32 families. The most notable finding is the G10K-VGP human trio (mHomSap3), but only the son's PacBio data is publicly available — the parents' data was not deposited in the accessible projects. One controlled-access autism family study (phs002698, 5 members, PacBio HiFi) was found but requires dbGaP application. The DDBJ and GSA-Human repositories could not be searched due to API access restrictions.
