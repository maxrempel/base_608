1. **No calibration pilot possible:** The thirteen 1000 Genomes controls lack independent serological or molecular RHD truth labels. Without a reference standard, sensitivity and specificity cannot be estimated; computational predictions from the same WGS data (e.g., Erythrogene, RBCeq) are not acceptable substitutes because they are not orthogonal and may recapitulate the same bioinformatic biases. Any calibration requires known positive/negative status, which is absent.

2. **Minimum truth-control manifest and fail-closed gate:** Each truth sample must carry, at minimum, a unique sample identifier, the verified RHD genotype/phenotype (with zygosity), the truth-assay method (e.g., serology, PCR, Sanger sequencing) and its performance characteristics, the laboratory performing the assay, and the date of truth determination. A fail-closed gate dictates that if any mandatory field is missing, unverifiable, or derived from the test WGS data itself, the sample is rejected. Only samples with complete, externally confirmed truth metadata are admissible.

3. **Smallest acquisition specification:** Two GRCh38 short-read WGS samples with orthogonal truth. Sample‑A: conventional RHD‑positive (D‑positive serology, intact RHD gene confirmed by exon‑specific PCR or long‑range PCR showing no deletion breakpoints). Sample‑B: homozygous whole‑RHD deletion (D‑negative serology, molecular absence of all RHD exons, e.g., negative PCR for RHD exons 3,4,5,7,10, and presence of the hybrid Rhesus box). Preferred additional specimens: a heterozygous deletion (one copy deleted, confirmed by quantitative PCR or MLPA) and a well‑characterised hybrid/partial allele (identified by commercial RHD genotyping kit or allele‑specific sequencing). All truth assignments must be generated independently of the WGS data.

4. **Observables for false positives and false negatives:** With defined truth controls, a false positive occurs when a tool calls a sample RHD‑positive or hybrid but the truth is D‑negative or homozygous deletion. A false negative occurs when a tool calls a sample RHD‑deletion or D‑negative but the truth is D‑positive (including weak/partial D with detectable antigen). These can be observed by cross‑tabulating tool output with the orthogonal truth label; discordant cells constitute false calls.

5. **Why two tools on the same reads are not independent validation:** Delly and RHtyper both operate on the identical aligned WGS reads. Any systematic error in that single data source (e.g., alignment artefacts, coverage drops, sample swaps, contamination, reference bias) affects both tools, inflating concordance and masking true error. Independence requires orthogonal evidence, such as serology, long‑read sequencing, or targeted genotyping on a separate DNA aliquot. Algorithmic diversity alone cannot break data‑dependency; validation demands evidence from fundamentally different experimental methods.
