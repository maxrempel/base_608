**Compact Review**

The diagnostic is fair in the sense that it applies the same gates uniformly to all contigs across all PAF alignments without using locus coordinates, thereby avoiding circular bias toward known signals. It correctly inspects every alignment for the defined terminal-event or internal-insertion pattern rather than defaulting only to the primary.

**Limitation**: The per-contig selection of the *longest aligned-query candidate* among qualifying alignments conflates multiple independent junction events on the same contig into a single representative. This systematically undercounts true secondary/supplementary events when a contig harbors more than one qualifying junction, and may inflate false positives if the longest qualifying alignment is not actually a junction (e.g., a long near-perfect alignment that marginally meets overhang/slack gates due to assembly artifact). Additionally, without using locus coordinates during selection, a single contig spanning both a signal and a sham window will be assigned to only one window (likely the one with longer query coverage), biasing recovery and false positive reporting. The diagnostic is therefore a crude upper-bound estimator that sacrifices resolution for uniformity.
