**1. Safe headline**  
Culture status is a primary confounder. S3’s apparent Omun rate (0.375/Gb) cannot be compared to cultured controls (mean 70.3/Gb) for biological enrichment/depletion.

**2. Conclusion withdrawn**  
Any claim of S3 Starseed-control difference is blocked. Only a culture‑matched design can test biological signal.

**3. New primary confounder rule**  
All Omun‑burden comparisons must match on culture status (uncultured/blood vs. cultured). Ancestry, sequencing platform, coverage, and callable opportunity must also be matched.

**4. Smallest practical matched‑control design**  
Require ≥2 uncultured or blood‑derived controls per S3, matched 1:2 on ancestry, platform, sex, and coverage (±10%). Minimum n = 4 controls (2 per S3 replicate if available). This preserves statistical power while controlling the dominant confound. Larger sets (≥10) preferred but not minimum.

**5. Technical tests that still matter for S3**  
Read‑support attrition, right‑overhang proxy checks, and callable‑base filtering remain valid for S3 data quality. Culture status must be coded as a covariate in any later combined model.

**6. How existing cultured 20 controls should now be labeled**  
“Cultured technical reference panel – not for biological comparison with uncultured samples.” Use only for sensitivity analyses (e.g., assay stability over culture conditions).
