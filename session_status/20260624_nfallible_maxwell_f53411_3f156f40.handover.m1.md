## DECISIONS + WHY

**Two candidate approaches were identified, neither chosen yet:**

1. **Silent auto-update via scheduled task (Path 1)** - Disable Nextcloud's own in-app updater entirely, then create a Windows scheduled task that runs periodically (e.g. monthly), downloads the latest Nextcloud client, installs it with the `/S` (silent) MSI/installer flag. The client closes, updates, reopens - zero user interaction. *Preferred by Claude for elegance and total hands-off operation, but means taking ownership of the update cadence.*

2. **Re-point the existing updater to use silent mode (Path 2)** - Keep Nextcloud's built-in updater but reconfigure it so when it triggers, it uses a silent install path that skips the wizard and UAC prompts. *Lighter touch, but unclear how much of the dialog Nextcloud's own updater actually allows you to suppress - needs investigation.*

**Decision not yet made.** Claude recommended a read-only reconnaissance step first: inspect the actual Nextcloud installation on the machine named "Pine" to determine version, install type (MSI vs .exe), and current update configuration before committing to either path.

## GOTCHAS

- **No actions taken yet** - nothing to undo, nothing ruled out.
- Silent install `/S` flag works for the NSIS-based .exe installer but **not** for MSI - if the client is MSI-installed, the flag would be `/quiet /norestart` instead. Need to verify before writing the automation.
- Disabling the in-app updater may leave Max without update notifications. If Path 1 is chosen, a separate notification mechanism (or just trusting the scheduled task) is needed.
- UAC prompts during install are a separate issue from the Nextcloud wizard. Silent install may still trigger UAC unless the scheduled task runs with highest privileges or UAC is configured appropriately.
- The word "troubl" in Max's prompt was likely "troubleshooting" - Max wants this to work reliably without becoming a new source of maintenance pain.
