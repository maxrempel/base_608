## DECISIONS MADE + WHY

### Board Content Gate (bcast.py)
- **Extend DeepSeek gate to cover ALL posts to the X board, not just joint-board posts.** The old code only checked cross-team posts; team-board posts went through unfiltered. That's how minute-by-minute work reports poured in.
- **Hard-block, not soft-nag.** Max said "prevents any stupidity from leaking" - so the gate refuses the post and redirects to a room. No compliance required.
- **DeepSeek Flash writes the refusal itself with escalating language.** Offense counter per session: strike 1 polite, strike 2 impatient, strike 3 stern, 4+ zero-tolerance. Clean post resets the counter. The refusal is an LLM-generated order, not canned text.
- **Fail-open if DeepSeek is down** - never blocks real coordination traffic.
- **Scoped to X team only** via a flag file (`board_gate.x.on`). Other teams keep posting freely until Max says otherwise.
- **Criterion is Max's exact words:** a post only passes if it's of *common use between multiple groups/sub-projects* - shared data/resources, danger alert, or Max command.

### DeepSeek Model Switch - Reliability
- **The gate was using `deepseek-v4-flash` (reasoning model), which frequently returned empty replies** because reasoning tokens consumed the budget before the visible answer. This was the "empty every other day" problem Max complained about.
- **Switched all gate calls to `deepseek-chat` (non-reasoning) via a single hardened helper** that retries once on empty/error. Fixed the root cause, not just a band-aid.
- This was NOT a money or outage problem - the API was healthy, the model choice was wrong.

### DeepSeek Cost Audit + Watcher Fixes
- **The two Pine watchers (`safety_watcher.py` and `watcher.py`) were the daily drip:** both fired every 10 minutes on `deepseek-v4-flash` (reasoning model). `watcher.py` reported nothing to the ledger - that's where the 84% invisible spend went (~$44.90 of $53.71 lifetime).
- **Converted both watchers to `deepseek-chat`.** Savings start on the next 10-minute tick.

- **One-shot scripts (cc_recover, harvest, ttt/psi summarizers) left alone** - they genuinely need the smarter model and only run on human launch.
- **fleet_monitor already cheap** - only calls DeepSeek when a check is DOWN; near-zero cost when fleet is healthy.
