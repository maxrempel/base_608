## DECISIONS MADE + WHY

### 1. SMS was explored and rejected for Russia/Ukraine
- **Research result (Aug 2025):** Russia blocks ALL SMS containing a URL as spam. An Aug 2025 law also blocks all business/A2P SMS by default. No US provider can beat this - it's the Russian network, not the vendor.
- Ukraine works but is "best-effort" with silent drops. Israel/Germany/US work fine.
- **Decision:** SMS via Twilio/Telnyx/Plivo is the wrong channel for a Russian-speaking audience. Use **Telegram** instead (free, universal, works identically across RU/UA/IL/DE/US).

### 2. Telegram: Private Channel with Admin Approval (not a bot, not a group)
- **Bot approach considered:** a bot that DM's the link to each approved person individually. Requires each person to press "Start" once and an allowlist. More setup overhead.
- **One-way group considered:** Telegram doesn't have a "read-only group" for 200 people; a channel is the native one-way broadcast tool.
- **Final choice: Private Telegram Channel "?????-????", join-by-approval.** Only admins post (the rotating link); subscribers just read. Every join request waits for Max's personal approval - that's the identity gate against impersonators. The channel membership IS the verified trusted list.
- A friendly redirect was created: **tamza.com/telega** ? the private channel's approval-link invite. The ugly random URL (t.me/+D7nxFaemjjRiNWUx) is the price of privacy - custom usernames require a public, un-gated channel.

### 3. Facebook Group created separately (not a Messenger chat)
- Messenger group chats cannot do: one-way posting, message approval, or link-plus-approval joins (the link lets anyone in instantly with no gate).
- **Facebook Group** (Private + Hidden, admins-post-only, approve-to-join, screening questions) was created by Max in parallel. It's the Facebook twin of the Telegram channel.

### 4. Zoom API: Server-to-Server OAuth app (not browser automation)
- Zoom has a full REST API. A **Server-to-Server OAuth app** was preferred because it works fully headless (Python scripts, no login/passwords) and can create meetings programmatically.
- Built under admin@tamza.com on the Marketplace. Activated with scopes: meeting:write:meeting:admin, meeting:read:meeting:admin, user:read:user:admin.
- **Decision:** Create **8 separate, fresh meetings** (not one recurring meeting reused) - because secrecy demands changing links, and a recurring meeting link stays the same forever.
