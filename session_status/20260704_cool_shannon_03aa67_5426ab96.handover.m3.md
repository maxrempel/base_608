## DECISIONS MADE + WHY

### 1. Worker-death root cause & fix (DONE, committed + live)

**Found:** The image worker (`combo_worker.py`) polls Cloudflare D1 over the public internet in a `while True:` loop. The loop was wrapped in `try:`/`finally:` with **no `except:`**. Transient network errors (WinError 10054 connection reset, read timeout) during the DB poll escaped to `finally`, which closed the connection and exited the process. Every internet hiccup = dead worker.

**Fix applied (two layers, per Max's preference for long-term elegance):**

- **Layer 1 - `moma_db.py` `_request()`:** Added retry-with-backoff for transient network errors. Catches `URLError`, `TimeoutError`, `OSError` (socket/connection); retries 4 times with sleeps 0.5s, 2s, 5s, 10s. On final failure, raises `Exception("D1 network error after 4 retries: ...")`. `HTTPError` is NOT retried (real API errors should surface). Required adding `import time`.

- **Layer 2 - `combo_worker.py` `main()` loop:** Wrapped the loop **body** in `try:/except Exception:` so ANY DB error logs a warning, sleeps 30s, and continues instead of killing the process. The outer `try:/finally:` remains for clean exit on SIGINT/SIGTERM.

Both files edited, parsed clean, committed+**pushed to master** (commit: "Fix recurring worker deaths: survive transient D1 network errors"). Full restart performed - all 6 workers + 3 servers verified running with the fix live. Prompter (port 8791) needed a manual launch; the restart script skipped it - noted.

### 2. The "minimal edit, NOT derivative" lesson (stored in memory)

Max was furious about derivatives: the AI deteriorated images badly when the output was fed back as a primary reference. The principle:

- **Keep the original formula's inputs UNCHANGED** - same portrait refs, same room ref, same size ref.
- **Re-describe from scratch** in text.
- **If adding a result image as reference, put it as ref 2 or 3, NEVER ref 1.** Ref 1 = the primary "reproduce exactly" source; feeding an output there makes every subsequent generation a derivative of a derivative.
- **Always look at the actual images**, not just trust the prompt.

This was captured in `feedback_minimal_edit_not_derivative.md` and linked in MEMORY.md so future sessions can't miss it.
