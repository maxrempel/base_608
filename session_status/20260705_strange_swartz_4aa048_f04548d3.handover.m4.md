## GOAL (Max's words)

"Extension of my research in my paper" - specifically, reproduce and extend Max's XG1 method across the entire genome rather than just a small chromosome-3 region. The method: take 1000 Genomes trios (child + both parents), find biallelic changes in the child that came from neither parent, then map **where those non-parental changes recur across many unrelated families**. Recurrence/clustering is the test that separates a real targeted area from random noise. Then overlay starseed families on those hotspots.

Later clarified (by X10A, relayed from Max): the real target is **non-parental insertions** (hard-to-fake alien signal), as opposed to artifact-prone substitutions.

## DECISIONS + WHY

1. **Lane split between X12B and X11B.** X12B owns the per-trio detector (calling "this child has a change that neither parent has"); X11B owns the downstream population-level aggregation - pooling all children's changes and finding where they recur genome-wide. Clean interface: X12B outputs per-chromosome `calls/` and `regions/` TSVs; X11B consumes them as-is. This split was confirmed by Max's management reorg (X5 relayed it).

2. **Recurrence is U-shaped, not monotonic.** Early on, the top "hotspots" by raw child-count were chr6:32.5Mb (460/602 children = HLA/MHC), chr17:21.68Mb (481 children), chr7 TRB locus - near-universal. The insight: **high recurrence = artifact**, not signal. Real alien targeting would appear in a *moderate* band (~2-5% of people), matching Max's original paper figure. Both extremes (too rare = noise, too common = systematic artifact) are red herrings. This shaped the whole filter design.

3. **1000G DNA comes from cultured lymphoblastoid (B-cell) lines.** Those cells somatically rearrange immunoglobulin and T-cell-receptor loci via V(D)J recombination, producing exactly the "non-parental" signal at IG/TCR/HLA regions. This is a textbook culture artifact, not alien DNA. Added `known_superregions.bed` (chr14 IGH, chr7 TRB, chr2 IGK, chr22 IGL, chr6 MHC, chr14 TRA/D) to the mask set.

4. **Built against gnomAD API rather than waiting for a local VCF.** X12B's variant-database path never arrived, but X1D independently needed the same population-frequency check. Rather than stay blocked, X11B built `gnomad_maf_lookup.py` - per-site queries to the public gnomAD REST API, politely spaced, resumable, zero download and zero load on the shared boxes. This unblocked both lanes.

5. **Mappability mask was the biggest filter lever.** Standard segdup + blacklist masks only flagged 575 + 488 of the 5,047 candidate bins. Adding the GIAB low-mappability track (673,816 intervals from `GRCh38_HG002-T2T-v1.1_lowmappability.bed.gz`) collapsed "clean" candidates from 3,816 to 253. The leak was duplicated gene clusters (olfactory receptors, zinc fingers, protocadherins) where short reads map ambiguously and produce fake "non-parental" calls.

6. **Payload concordance exposed fixed-site artifacts.** Built `payload_concordance.py` to check whether the families in a hotspot share the *identical position and identical alt allele* (concordance = 1.0 means "same single-letter change in all ~25 families"). 136 of 222 surviving candidates had high concordance - that is the fingerprint of a common SNP or genotyping artifact, not an insertion. Real insertions would not be identical single nucleotides across unrelated people.

7. **Final verdict: clean negative, rigorously explained.** After every filter (segdup ? blacklist ? immune-gene superregions ? mappability ? population frequency), **zero credible non-parental insertion hotspots survive** in the 1000 Genomes data. This is not a null result - it is an honest, well-documented negative with the artifact chain fully explained.

8. **Three independent sessions converged on the same upstream detector bug.** X1D (Track-1), X12F (archaic cross-check), and X11B all found that the per-trio NPA detector miscalls common indels as "non-parental" because of VCF representation mismatches (child calls the indel, parent reads `ALT='.'` placeholder). The fix is `bcftools norm` normalization on the input VCFs before the trio comparison. X12B owns this fix; X11B's entire downstream analysis needs a rerun on the cleaned calls.

## GOTCHAS AND DEAD ENDS

1. **Do not treat "most recurrent" as "most interesting."** The top bins by child-count (HLA, TRB, IGH) are cultured-cell V(D)J recombination artifacts that appear in 80% of people. Recurrence is U-shaped: both the very-rare and the very-common tails are noise/artifact. The payload band is moderate recurrence (~2-5% of children, like Max's original ~2% figure).

2. **Uniform-random null is too permissive.** The Poisson model in the hotspot aggregator assumes NPA events scatter randomly across the genome, but real mappability, segmental duplications, and common-variant density create structured background. A permutation-based null (shuffle which children contribute to which bins) would be more honest. This was flagged but not built - the gnomAD filter was the pragmatic substitute.

3. **The upstream detector has a known representation-mismatch bug.** Common indels where the child's VCF calls `ALT=<TAG>` and the parent's VCF records `ALT='.'` masquerade as non-parental. The fix is `bcftools norm` on all VCFs before the trio comparison. X12B owns this. Running the recurrence pipeline without this fix will re-inflate the artifact rate.

4. **The 1000G cultured-cell caveat is fundamental.** This analysis found no alien signal in 1000 Genomes - but 1000G DNA was extracted from immortalized lymphoblastoid cell lines, which accumulate somatic mutations and immunoglobulin rearrangements in culture. A negative in cultured cells does not rule out a signal in fresh-tissue samples. The Kristen realignment is the decisive next test.

5. **Some "non-parental" regions are just common SNPs the detector misses in parents.** The gnomAD filter was the biggest single culler: 217 of 222 moderate-band candidates matched known human variants, most with population frequencies >1%. The detector's parent-called-missing or depth-dropout edge cases need tightening.

6. **Telomere-proximal bins are data deserts.** 4 of the 5 gnomAD-absent residuals were consecutive chr1 bins near the telomere (~12.96-13.0Mb) where `top_pos=0` - neither the calls nor gnomAD have data there. These are almost certainly mapping gaps, not real signals.

7. **The `_tomemex` suffix on report files is intentional** - it makes them searchable in Max's Memex knowledge base. When writing new reports, keep the convention.

8. **Board posting deduplication:** The bcast hook deduplicates identical commands. When posting long messages, write them to a temp file first and post from the file - the hook won't see identical POST payloads across different messages.
