- **If network-discovery disabling doesn't fix it**, the next investigation should check whether antivirus/security software is intercepting VLC's launch (some AV suites scan every DLL load and add multi-second delays).
- **Plugin cache rebuild:** simply deleting `plugins.dat` and restarting VLC will trigger a fresh, clean cache rebuild - this takes a few seconds once and then resolves. No GUI needed.
