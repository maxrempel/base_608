4. **po_token (proof-of-origin token) is the other escalation.** A small background service (`bgutil-ytdlp-pot-provider`) mints a token locally that makes cookieless yt-dlp requests look like a real YouTube player. NOT guaranteed against a hard-flagged IP, but the standard durable fix. Needs no login. Setup: install bgutil, run it as a service, point yt-dlp at it via `--extractor-args youtube:po_token`.

5. **VPN/datacenter IPs are WORSE** - auto-flagged, 20-40% success. Sol's residential home IP is the actual asset.

6. **Cookies from a throwaway Google account, NEVER Max's main account.** Feeding Max's real account cookies to a bulk downloader risks banning the account that owns the Tamza channel.
