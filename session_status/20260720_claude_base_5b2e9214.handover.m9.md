- **`-shortest` alone isn't enough** - leaves ~9ms residual per segment; only the concat filter fully prevents drift.
- **trimmer2** must be used for chapter cut-points - snaps to Deepgram sentence boundaries, not raw word times. Cuts must start at sentence beginnings (mid-sentence starts are "very bad"). Ending mid-sentence is acceptable.
- **R2 lifecycle:** The temp4/ expiry rule is set via wrangler (`npx wrangler r2 bucket lifecycle add maxrempel-papers "temp4-expire-14d" "temp4/" --expire-days 14`). If re-uploading, old files must be explicitly deleted (upload doesn't overwrite).

- **The `jobs.engine` DB default is `'wan22'`** - lipsie jobs fired without explicit engine will race with the silent-clip worker. The guardrail now sets `engine = lipsync_tool or 'wan26flau'` for lipsies.
