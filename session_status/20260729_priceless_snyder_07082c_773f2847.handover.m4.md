## DECISIONS MADE + WHY

### What "Prompter" actually is
H03 built an automated reel-prompt generator: `scripted_reel_pipeline_v02.py` (in `C:\moma\sc10\combo_runner\code`). How it works:
1. Takes one spot (one lesson line, usually 2-5 sentences Anna speaks).
2. Sends the full spot sentences to **DeepSeek** (cheap language model) along with a list of ~16 **approved gestures** and their meanings. DeepSeek reads each sentence's *meaning* and picks the fitting gesture id, or marks it "stillness" if nothing fits.
3. Python code adds safety rails: bans palm-up/offering gestures (re-routes to stillness), enforces right-hand only, drops duplicate gestures within a reel, caps total gesture count (~1 per 4-5 seconds of audio).
4. Assembles the final text prompt from a locked header (candlelight, alone, etc.) + a mood line + per-sentence "from X to Y seconds, as she says '...', [gesture]" + a closing taming line ("mostly still, restrained").
5. In dry-run mode (`--dry-run`), it prints the assembled prompt, makes no database writes, fires no lipsie job, spends zero money.

### Why a real git fork
Max explicitly said "a real fork" - so this session created a **genuine separate git worktree** at `C:\moma_forks\prompter`, off the `prompter` branch (forked from master at commit `0108845`). This isolates all optimization work from the shared checkout at `C:\moma` and from other sessions' live work. The original `scripted_reel_pipeline_v02.py` is confirmed byte-identical (untouched).

### What was optimized in `prompter.py`
The original v02 left most spots gesture-free (6 of 9 sample spots got zero meaningful gestures). The optimized `prompter.py` improves:
- **Sharper DeepSeek instruction**: gestures concrete images, actions, contrasts, and spatial lines when an approved meaning fits; keeps stillness only for truly abstract lines. Added few-shot examples from approved reels.
- **Expanded + rotated resting poses**: 14 varied descriptions, start index varies per spot - kills the original's identical interlaced-hands opening on every reel.
- **Rhythm technique** on ~25% of reels (spot number divisible by 4): "palms open while speaking, settle at phrase end" - Max approved this pattern.
- **Looser gesture cap**: `/4` seconds instead of `/5` (still one gesture per sentence, still demotes surplus).
- **Tighter mood line**: clamped to ?6 words, normalized.

### What was deliberately NOT changed
- Every safety gate preserved: banned/palm-up ? stillness, right-hand enforcement, in-spot dedup, duration cap, caption/text negative terms, candlelight header, "completely alone in the room" clause.
- The ~16 approved-gesture vocabulary is **fixed** - expanding it is Max's call. Vivid meanings like *light, heavy, build* have no approved gesture and correctly stay still.
- All work is **dry-run only**. Zero lipsie jobs fired, zero database writes, zero render spend. The tool prints "No job fired, no state/log written."

### Why the original v02 was preserved byte-identical
So Max can run a clean side-by-side comparison: `scripted_reel_pipeline_v02.py` (original) vs `prompter.py` (optimized) on the same spots. Nobody touches v02; nobody merges to master without Max's explicit go.
