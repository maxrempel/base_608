## GOTCHAS

- **Do NOT run `smail sync` directly** - the stock CLI loads everything into RAM. Always use the chunked driver.
- **The CLI is interactive** - `smail search` asks "Do you want to skip generating a summary?" and waits for y/n. Must pipe `printf 'n\n' |` to bypass, OR query ChromaDB directly from Python.
- **UNICODE on Windows CMD:** Rich library crashes on checkmark emojis. Always set `PYTHONUTF8=1 PYTHONIOENCODING=utf-8` before invoking smail.
- **OpenAI batch failure was real** - one >8192-token email was killing whole batches silently. Our patch fixed this, but be aware if indexing errors appear: check for very long emails.
- **ChromaDB is empty** for any unindexed months. The chunked driver commits incrementally; search only sees committed months.
- **Gmail API rate limits** - the driver hits them, pauses, and resumes. "Fetching emails" messages with no count increment is normal throttling, not a crash.
- **The y/n prompt in `--clear` killed the first detached attempt** - never pass `--clear` to a detached process; the chunked driver handles clearing by creating a fresh collection internally.
- **Laptop sleep pauses everything** - the indexing process is just a Windows process. It resumes exactly where it left off (chunked driver skips months already in `chunks_done.txt`).
