### 3. Stabilization - long road to the correct method
- **First try:** vidstab with default smoothing + rotation allowed ? Max saw twitching every ~1s.  
- **Diagnosis 1:** Variable frame rate (OBS records with 1 ms timestamps, 30fps impossible ? 33/33/34 ms wobble). vidstab assumed CFR. Fix: force `fps=30` into stabilizer.  
- **Second try:** Tripod mode (locks all frames to first frame) - Max saw "super high shaking ... clockwise, counterclockwise" later in clips.  
- **Diagnosis 2:** Tripod mode pins to frame 1. Late in an 84-min recording, baseline shift makes vidstab fight harder, and rotation correction oscillates. That's the rotational shake.  
- **Final fix:** Use **smoothed mode** (follows moving average, no baseline drift issue) + **disable rotation correction entirely** (`maxangle=0`). Also keep `fps=30` forced.  
- **Proof:** Built `samples/stab_fix2/END_smooth_new.mp4` (smoothed, no rotation, CFR) vs `END_tripod_current.mp4` (current bad). Max has **not yet confirmed** this proof.
