## DECISIONS MADE + WHY

1. **Which still / which line** - Max said "from this static image" without naming it. Researched the 6 most recent reels: 5 of 6 were iterating ISHTAB L23 on `sc_walk2_c2_orig_B_v01.png`. The "walk slowly but gesture" description also matched the corridor arrangement (arr4). Decided this was the unambiguous target.

2. **Prompt design for gestures** - Broke the line into 4 phrases, assigned a *different* natural gesture to each (palms-down, single raised hand, wide encompassing sweep, hands-draw-together-then-offer). "Wide sweep" replaces earlier "globe/circle" gestures to avoid the negative-prompt object artifacts (DashScope kept generating floating globes between her hands).

3. **Negative prompt** - Explicitly blocks `floating globe, planet, Earth, sphere, orb, hologram, glowing ball, any object between her hands, extra image, glossy skin, makeup`. This was learned from prior failed L23 takes that produced a CGI globe floating between the speaker's hands.

4. **silence_buffer 0.9** - Slightly longer than default 0.5 to give gestures breathing room across the long line.

5. **Worker pid file fix** - The wan26au reel-render worker kept dying silently on startup. Root cause: its singleton pid file lived on Nextcloud (`.../combo_runner/data/wan26au_worker_pid.txt`), and Nextcloud's VFS had turned it into a locked/corrupt online-only placeholder (0 bytes, bogus 1600 date, Errno 22 on write). The worker crashed immediately after logging "started", before ever polling for jobs. **Fix**: moved the pid file to `local_state/wan26au_worker_pid.txt` (off Nextcloud, inside the repo). This matches the identical precedent where `FEEDBACK_STATE_FILE` was moved off Nextcloud for the same VFS-lock reason. Committed + pushed to master.

6. **Launch method** - The worker must be truly detached. `start /B pythonw` from git-bash didn't survive. Used a Python launcher script with `CREATE_NEW_PROCESS_GROUP | DETACHED_PROCESS | CREATE_NO_WINDOW` (0x08000208) + `subprocess.Popen` - this gave proper background survival.
