### 2. Wide search across Walmart, Costco, Best Buy, Amazon, eBay
- **Nothing better exists at the same ~$1,850 price** - the original config (Ryzen 9 9900X, 5060 Ti 16GB, 32GB, 2TB) was genuinely good value
- **The 5080 at Costco ($2,700) was ruled out** - same 16GB VRAM ceiling as the 5060 Ti, so $870 buys faster bad output, not better quality
- **The middle band is dead** - 5070 Ti builds run $2,350-2,750, near the 5080 price for less card and worse terms
- **No cheap machine keeps both 12 cores and 2TB storage** - every 2TB config comes welded to a $1,000+ GPU (gaming rig economics)
- Wound up comparing three options and settled on the Dell

### 3. CyberPowerPC brand assessment
- 66% five-star, 22% one-star on Trustpilot - signature of a quality-control problem, not a bad design
- Complaints repeatedly mention defective parts out of the box (including RAM specifically), slow support, return shipping at customer cost
- **Decision: buy a different brand** - the memory faults probably weren't bad luck, you landed in the 22%

### 4. Chose the Dell Tower from Costco ($1,299.99)
- **Intel Core Ultra 7 265F (20 cores)** - about 10% slower multithreaded than the Ryzen 9 9900X it replaces. Admitted honestly after initially overstating the CPU
- **RTX 5060 8GB** - enough for Whisper/dictation (~3.9 GB) and voice synthesis, not enough for local video generation (~16.4 GB needed). Max confirmed this trade is acceptable
- **32GB RAM (single stick)** - leaves an empty slot; add a second 32GB stick for ~$100 to get 64GB and full dual-channel bandwidth
- **1TB NVMe** - add a 2TB drive for ~$120; total ~$1,520 all-in vs $2,070 originally paid
- **Why Costco**: 90-day return window + 2-year warranty vs Walmart's 30 days + 1 year. Dell is a tier-1 manufacturer. The insurance on the return window alone is worth more than any spec upgrade
- **$500 off promo runs through Aug 16** - comfortably past the return deadline
- **Order #1304543892**, item 1951491, model DECT1250-7274BLK-PUS, $1,416.89 total (including $14.99 standard shipping + $101.91 tax), Visa ending 6391
- **McAfee and Microsoft 365 codes included for $0.01 each - DO NOT REDEEM** (auto-renewal risk; delete the emails, unredeemed codes are inert)
- **No Allstate plan purchased** - Costco already gives 2 years of mechanical/electrical coverage; the plan mainly adds drop/spill coverage irrelevant to a desktop tower

- **Decision: do a fresh Ubuntu install on the Dell using the SystemRescue USB stick**, then restore packages/configs/data from the inventory
- The full disk image was repeatedly offered but never started; later analysis showed it would have added essentially nothing - everything of value lives in the package list + /home, both of which are captured
