## BACKGROUND: Upload Flow Summary (for debugging)

The publish process (from `odysee_upload.py`) uses the Odysee API directly:

1. Get JWT: `POST /api/v1/asynqueries/uploads/` with `x?lbry?auth?token` ? returns `jwt` and `location` (tus base URL).
2. Tus upload: `POST <location>/` with JWT bearer, `upload?metadata` (filename), `upload?length`; then `PATCH` with bytes (throttled).
3. Publish: `POST /api/v1/asynqueries/` with body containing `method: "stream_create"`, `channel_id`, `bid: 0.001`, `title`, `description` (contains YouTube link for dedup), `file_path` = the tus upload destination.
4. Poll: `GET /api/v1/asynqueries/<query_id>` until complete; the response provides the claim's permanent URL.

If `publish` returns `InsufficientFunds`, the uploader stops with a clear log message. If the initial wallet check shows less than 0.05 LBC, it refuses to start, avoiding wasted bandwidth.
