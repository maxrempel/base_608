**2. Signal definition locked** - The detector looks for **non-parental alleles (NPAs)** = a SNP where the child has an allele found in neither parent. But isolated single NPAs are noise (sequencing errors, bad-DNA dropout faking homozygotes). Only **haplotype runs** (consecutive NPAs in sliding windows) count as real signal. The paper used 60-SNP windows, 20-SNP steps, threshold ?5 NPAs per window, classified as Normal (<10), Possible-hybrid (10-19), or Definite-hybrid (?20). Detector built reusing Max's original logic.

**3. Architecture split** - Two-part pipeline:
- **X12B (me): per-trio detector** - takes VCF + pedigree, outputs per-child NPA haplotype regions

Both halves are built and synthetic-tested. Input/output schema agreed (one file per trio, per-variant rows).

**4. Data source** - 1000 Genomes NYGC 30x GRCh38 high-coverage VCFs, genotypes only. Located at `s3://1000genomes/1000G_2504_high_coverage/`. 3202 samples, per-chromosome files. Pedigree: `20130606_g1k.ped` (matched to these samples). Max's old Sirius copy is likely inaccessible - going via S3 directly.
