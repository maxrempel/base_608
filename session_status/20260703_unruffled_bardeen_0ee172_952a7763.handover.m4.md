### 4. Upload API reverse-engineered (via one real test upload)
Captured the full Odysee publish flow by uploading a 9.9 MB test video through the browser with network logging:

1. **Mint a tus upload token:** `POST https://api.odysee.com/api/v1/asynqueries/uploads/` with header `x-lbry-auth-token: <token>`. Returns JSON with `upload_url` (tus endpoint), `location` (upload GUID), `token` (JWT for tus auth).
2. **Upload the file via tus resumable protocol:**
   - `POST <upload_url>` with `Authorization: Bearer <jwt>`, `Upload-Metadata: filename <base64>,filetype <base64>`, `Upload-Length: <bytes>`. Returns `Location` header with the tus upload URL.
   - `PATCH <tus-location>` with raw file bytes in body, `Content-Type: application/offset+octet-stream`, `Upload-Offset: 0`.
3. **Publish:** `POST https://api.odysee.com/api/v1/asynqueries/` with header `x-lbry-auth-token: <token>`, body = JSON `method: "stream_create"` with params: `name`, `title`, `description`, `bid: "0.001"`, `channel_id: "77c3f0e9..."`, `file_path: <tus-upload-url>`, `blocking: true`. Returns query_id for polling.
4. Server-side wallet signs automatically (no client-side signing needed).
