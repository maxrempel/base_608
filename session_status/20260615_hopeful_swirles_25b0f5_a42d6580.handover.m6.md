## DECISIONS MADE + WHY

1. **Root cause found:** The router's 2.4 GHz radio (`radio1`) was switched OFF entirely. The "Rempel" network Max saw on his phone was the 5 GHz radio. The Kidde alarm is **2.4 GHz-only**, so it saw neighbours' networks but nothing from Max's own router. This explains the pairing failure.

2. **Created temporary "KiddeSetup" network:** A clean 2.4 GHz, WPA2-PSK, channel 11, 20 MHz, no band-steering/no MAC filter/no client isolation SSID for pairing. Password: `kidde12345`. This was meant to be temporary - Max explicitly dislikes "proliferation of networks" (raised EMF pollution concern).

3. **EMF concern addressed:** Multiple SSID names on the same radio share one transmitter and one channel - the extra beacon frames add negligible RF. The only real RF addition was turning the 2.4 GHz radio back on at all, which is unavoidable for a 2.4 GHz-only alarm.

4. **Sibling-branch conflict:** A separate session/VM turned on 2.4 GHz on the main "Rempel" network, so the alarm paired there instead of KiddeSetup. **KiddeSetup became redundant clutter.** The user confirmed this is a branch situation.

5. **Paid subscription rejected:** During app setup, Ring pushed a subscription for 24/7 professional monitoring (~$5/mo). Max considers this "wicked" - he doesn't want to pay for minimal service. The alarm functions locally (siren) for free regardless.

6. **Free alerts confirmed:** From Ring/Kidde documentation: real-time push notifications to the phone for smoke/CO events are **free**. Only professional monitoring and extended history are paid. You must decline/skip the subscription offer in the app.

7. **Phone alert volume problem:** Max tested by putting the alarm under a pillow and pressing the test button. Result: a **single meek chime** in the Ring app - disappointing for a fire alarm. The issue is notification configuration, not the alarm hardware or the network.

8. **iOS vs. Android discrepancy:** Ring's "Critical Alerts" feature (loud, bypasses DND, bypasses silent switch) is an **iOS-only** thing. Max uses **Android**, so the fix is different: configure Android's notification channel system - set the alarm/emergency channel to Urgent/High importance, enable DND override, and pick a loud custom sound.

9. **"What do people say":** The session ended on this - Max wants external reviews/consensus on whether Ring/Kidde smoke alarms actually ring loudly enough on Android, and how real users test and configure them.
