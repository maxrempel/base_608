4. **Auth via Bitwarden + Playwright**  
   - No Odysee credentials were stored in the secure?logins file or on Centauri.  
   - Decision: use Playwright to log into Odysee with Bitwarden?autofilled credentials (max@tamza.com), capture the `auth_token` cookie, then use that token for programmatic API calls. 6. **Scheduled task & resumability**
