## GOTCHAS AND DEAD ENDS

1. **Cloudflare edge cache is aggressive.** Almost every verification required 2-3 retries with random cache-busters before the new content appeared. The worker deploys instantly but the CDN nodes lag. Always re-check 2-3 times.

2. **Cloudflare deploy tokens lack D1 read access.** The deploy token (`ZUyIUYjo_...`) can deploy workers and set secrets but cannot query D1 via REST. The MCP uses OAuth for D1 access. For the signup feed, the worker itself queries D1 (it has the binding) and exposes results via a secured endpoint.

3. **Centauri SSH uses cmd.exe, not bash.** Shell commands must be Windows-native (`dir`, `findstr`, `schtasks`, `if exist`). The SSH banner corrupts scp's binary protocol - use base64-over-ssh pipe for file transfers.

4. **Russian version uses comma decimals.** When updating the age counter and prices, the Russian locale needed `,` not `.` (e.g., "2,0" not "2.0").

5. **The site is a single 500+ line worker.js.** No framework, no build step. Inline HTML/CSS/JS. All pages are functions returning template literals. Routes are regex-matched in the fetch handler. The D1 binding is `env.CONTACTS_DB`.

6. **The Google Forms still exist at their old URLs.** They are unlinked from the site but still accept submissions. Max explicitly said not to delete them. If someone finds an old link, their submission goes to Google Sheets but NOT into the contacts DB (no longer synced automatically). Documented in `C:\claude_base\tools\xg1_starseed_forms\xg1_starseed_forms_method_v01_tomemex.md`.

7. **"Greenland1" case identified.** During the contacts DB migration, the detailed questionnaire matched Lottie Bowater (24 teeth, hypermobility, autistic, grandfather flew the 1952 North Greenland expedition). This was the trio flagged for the old $6K long-read ask.

8. **The age counter is client-side JS.** It computes from July 1, 2024, updates every second, with a static fallback for no-JS. It does NOT survive in server-rendered HTML or search engine snippets - those show the fallback.

9. **The Centauri scheduled task uses pythonw.exe** (no console window). It runs under the maxre account (Centauri auto-logs-in). If Centauri is rebooted, the task auto-starts. Check with `schtasks /Query /TN StarseedSignupNotifier`.

10. **maxrempel.com blog posts are D1 rows, not worker edits.** They render instantly - no deploy needed. The schema is `(slug TEXT PRIMARY KEY, title TEXT, content TEXT, created_at TEXT, lang TEXT)`. Slugs must be unique.
