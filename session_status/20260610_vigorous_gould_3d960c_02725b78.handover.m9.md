## DECISIONS + WHY

- **B-rolls are modeled as silent "lines," not new machinery.** A b-roll becomes a libretto entry with empty/parenthetical text, gets a line_hash, and flows into the spine like any line - the media slot just holds a clip instead of a lipsie. Reasoning: the spine already orders lines; b-rolls are just silent lines, so no redesign. (Open idea, not yet built - a `[BROLL]` tag in the libretto so sass skips TTS. Not implemented this session.)
- **Music is a separate overlay layer, NOT part of moma's line model.** It rides on top of the finished spine timeline as one track with in/out times, independent of line boundaries - a final-assembly concern, not a moma redesign. This reframe was to calm Max's "panic." Not built; brainstorm deferred.
- **The 8s-title bug was diagnosed as a fallback-timer problem.** A b-roll is a silent clip with no per-line mp3, so the player hit its "no-audio" path and advanced on a hardcoded **2-second fallback timer**, while the 8s title kept playing (looped/muted) underneath - so Max only ever saw the opening sliver. Fix: a silent clip now plays **once** (no loop) for its **real video length** and advances when the video actually ends, with a safety timer derived from the true duration so it can't hang.
- **The fix is general, not a one-off.** It keys off "clip + no per-line mp3," so every future b-roll-that-is-a-clip is covered. Max confirmed this is what he wanted and explicitly declined extending it to still-image b-rolls.
- **The Assemble Video button was ported, not rebuilt.** It fires the same render endpoint the old (now-retired) mixboard button used. Sourced from git history.
