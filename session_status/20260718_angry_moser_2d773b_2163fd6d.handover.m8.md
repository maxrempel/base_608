## GOTCHAS + DEAD ENDS

### 1. NEVER circumvent MoMA
- The imagegen skill generated Anna stills outside MoMA. Max reprimanded this. Any future still must go through `fire_job` / combo_worker ? gpt-image-2. The imagegen skill is now disabled.

### 2. The wan22 engine default steals lipsie jobs
- `jobs.engine` defaults to `wan22` in the D1 schema. Until the guardrail was added to `fire_job`, any lipsie job without an explicit `engine='wan26flau'` was silently eligible for the deprecated silent-clip worker. Result: some reels rendered as silent clips. The guardrail in `moma_db.py` (`if job_type == 'lipsie' and engine == 'wan22' ? engine='wan26flau'`) prevents this for all scenes, forever.

### 3. Worker restart required after code changes
- The wan26au worker loads modules at startup. If you edit `audio_resolver.py` or `paths.py`, any already-running worker has stale code. Restart the worker (kill pid, remove `wan26au_worker_pid.txt` from local state dir, launch `combo_wan26au_worker.py`).

### 4. Concat filter is the drift-free join method
- Using `ffmpeg -f concat` (copy codec) on conformed-but-separate segments accumulates sub-frame audio/video length mismatches (~0.02s per segment ? ~2s over 46 segments). The fix is a **concat filter** (`-filter_complex "concat=n=N:v=1:a=1"`) - a single re-timed encode where every segment lives on one continuous timeline. This is the method Max's own `assemble_max2_v01.py` uses. Reuse it.

### 5. Deepgram punctuation is unreliable for sentence detection
- Regex-splitting on `. ! ?` over-corrects (e.g., abbreviations, mid-sentence pauses). Use Deepgram's `smart_format` sentence-level segmentation instead - it gives real sentence boundaries with timestamps. This is what trimmer2 uses.

### 6. Audio format: 28?34 clips (D42b)
- The original 28-clip manifest was v06. D42b updated to 34 clips (v09). The audio folder at `anna_audio/` now has 34 wavs. Always read `manifest.json` to know the current state - don't assume 28.

### 7. v04 vs v03 talk timelines
- The assembly cut-points must be computed against **v04's own transcript** (via Deepgram). v03 and v04 have different trims, so chapter boundaries shift. Host intro (Nadalee) is only in v03_clean[0:12.69] - v04 starts at Max's opening.

### 8. MoMA silence trim constants
