## GOAL (Max's own words)
"The idea is to learn from the existing human curated catalog. And then start indexing from scratch. Apparently only 55% is currently indexed."

Broader task: automatically index timecodes for concert videos - read transcript (via DeepSeek = "ds4flash"), search online for song names/authors, flag self-authored songs, merge duplicates, and use fuzzy full-text matching against the catalog to boost identification. The human timecoder team handles the hard cases through a game-like interface. Only ~55% of songs are currently indexed - the missing ~45% is the target.

Max's key directive on approach: **high precision, no guessing.** "Let's aim at identifying only what is clearly coming out - either a match by full text or a clearly announced authorship. And time coding everything. Then the human team will check and fill the blanks."

## DECISIONS + WHY

1. **"Failed" not "wrong"** - Max corrected the language. Unidentified segments are "failed to identify," not "wrong." Adopted.

2. **Two-output design (locked in `B14_indexer_design_v01_tomemex.md`):**
   - **Segments** = timecode every song boundary (starts/ends), even unnamed ones. Everything gets a timecode.
   - **Confident labels** = put a name ONLY when certain - either a full-text lyric match against the catalog OR a clearly detected spoken announcement of authorship. Everything else stays blank.
   - **Why:** an honest blank beats a wrong label. Humans fill the blanks in the game UI. No sloppy fallbacks.

3. **Clean division of labor with another session:** That session built a thorough starts+ends segmentation pipeline and is now testing it. B14's job is the **labeling layer on top** - not duplicating segmentation. B14 posted on the b-team bulletin board requesting a handover from that session (format, output location).

4. **Offline-first, free-first approach:** Prototype validation runs entirely offline on already-harvested transcripts (452 videos). Zero YouTube API calls, zero spend initially. The mass YouTube transcript harvest needs coordination with b9 (who is using the home IP for a 1558-video backup).

5. **Leave-one-video-out validation already proven:** Tested on 25 videos/2172 songs using ONLY other videos' human titles - 47% exact recurrence, 63% transcript-locatable. Combined recall is higher. This validates Max's bet.

6. **Web lyrics as the biggest lever:** For ~half of songs NOT in the catalog, pulling full lyrics from the web and matching them against transcripts (even poor-quality ones) will dramatically boost identification. This comes after the offline phase.
