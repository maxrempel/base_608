## GOTCHAS

1. **Python 3.11 is required.** Pine's default Python (3.12/3.14) won't work for this venv. Always use `C:\tools\whisper-writer\venv\Scripts\python.exe` or `pythonw.exe` to run it.

2. **`requirements.txt` is UTF-16 encoded.** If you need to read or modify it, decode from UTF-16 first. Standard `grep`/`cat` will mangle it.

3. **The `av` package won't install on 3.11** (no wheel, build fails). It's only needed for local Whisper mode. API mode doesn't need it, so skip it.

4. **Do NOT use `*main.py*` as a process filter when killing processes.** It matches unrelated MCP servers. Use `*whisper-writer*` in the command line to target only WhisperWriter processes.

5. **Run with `pythonw.exe`, not `python.exe`**, to avoid a lingering console window. The launcher bat file uses `pythonw.exe`.
