## GOAL (Max's words)

Reproduce and extend Max's published XG1 paper. The method: take 1000 Genomes **trios** (child + both parents), find **biallelic changes in the child that came from neither parent** (~2% of children, per Max's original finding), then **map those non-parental changes genome-wide** and identify **where they recur** across many unrelated families. Recurrence/clustering is the test that separates a real "targeted area" from random cell-culture noise. Then overlay the starseed families on those same hotspots.

The real target is **non-parental insertions** (inserted DNA in child, absent in both parents) - the hard-to-fake alien signal. But the immediate work uses SNP/genotype-level non-parental allele (NPA) calls.

## DECISIONS + WHY

1. **Two-track split (X11B vs X12B):** Max reorg'd via X5 - X12B builds the per-trio detector + chr3 positive control; X11B aggregates X12B's output genome-wide. Clean separation, no overlap.

2. **Recurrence-based hotspot detection:** X11B's aggregator pools each child's non-parental changes, counts how many *unrelated* children share each genomic region, tests against a random-scatter null (Poisson + FDR). The logic: a real targeted insertion appears in a moderate number of families (~2%); near-universal recurrence is itself an artifact signature.

3. **Artifact filter ladder (built incrementally):** Segdup ? blacklist ? HLA/immune-gene ? mappability ? culture-prone genes + antigen-receptor loci. Each filter was added as real data exposed leaks:
   - **Mappability filter** was the big one - collapsed "clean" hotspots from 3,816 ? 253. Classic segdup catalogs miss paralog clusters and duplicated gene families.
   - **Culture-prone genes + antigen-receptor flag:** X12B predicted BCL2/MAGI2 as LCL culture somatic hotspots; confirmed. V(D)J recombination loci (IGK/IGL/TRA/TRG) produce fake non-parental signal in lymphoblastoid-derived DNA. This is now banked as standard methodology.

4. **Max's chr3:75.5Mb flagship is a mapping artifact:** X11B initially overclaimed "positive control passes" but X12B caught the error. Verified: HG01505 (Max's flagship sample) has zero calls at chr3:75.5Mb in the clean modern-build analysis because that locus is a massive segmental-duplication block (296 overlapping duplicates). The signal X11B initially flagged there was a *different* artifact (14 unrelated people with identical base at 75,559,196). Max's published scanner had no duplication mask or depth filter - that's exactly how the flagship arose.

5. **Common-variant miscall mechanism:** Because the original method has no normalization/depth filter, common variants written differently (e.g., ALT=`<*>` vs ALT=`A`) in child vs parent VCFs get miscounted as non-parental. This is the root cause of ~95% of the signal. Confirmed independently by X1D on Track-1.

6. **No gnomAD offline database used:** All population-frequency checks go through the public gnomAD REST API (polite, resumable, 4s/query) - no big download and no load on shared machines.

7. **Git push freeze (in effect now):** X1D found a ~1GB log file swept into commit `3ce29e92` that blocks all pushes.
