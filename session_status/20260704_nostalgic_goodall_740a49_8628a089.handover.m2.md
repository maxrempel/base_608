### Toolkit: built and tested
`reskit` is a ~450-line Python file (`reskit.py`) with these tested features:

| Feature | What it does | Test result |
|---|---|---|
| `run` | Splits work into N chunks, processes them at CONC parallelism, skips chunks with `.done` markers | Pass - clean run, exit 0 |
| `resume` (atomic .done) | Rerun skips finished chunks; retries only failed ones; uses atomic `.done.tmp`?`.done` rename | Pass - 7 skipped, only part_003 retried |
| `status` | Shows X/Y done, per-chunk times, ETA from measured rate | Pass - accurate |
| `kill` | Kills orchestrator PID + all worker PIDs; no orphans, no relaunch | Pass + bug found and fixed |
| `ramp` | Saves PID, kills current run, relaunches at new CONC (free resume - done chunks skipped) | Pass |
| `pilot` | Process only first K chunks, then stop (deferred, not failed) | Pass |
| CRLF auto-strip | Strips `\r` from any bash-executed text on init | Pass |
| Enforced folder layout | `chunks/`, `light/`, `heavy/`, `logs/` + README generated automatically | Pass |
| Whole-process-tree cleanup | Zero orphan processes confirmed after kill | Pass - verified with PowerShell |

All tests ran on **Pine (Windows)** with a toy workload (`RESKIT_WORK_SECONDS` and `RESKIT_FAIL_CHUNK` env vars controlling behavior). **Not yet tested on a real genomic dataset** - only the toy workload.
