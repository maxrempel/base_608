## BUGS FIXED (permanent lessons)

1. **Long emails kill OpenAI embedding batches.** If a single email exceeds 8,192 tokens, the entire batch fails silently. The fix: truncate each email to a safe token limit using `tiktoken`. Applied in `openai_embedder.py`.

2. **The stock semantic-mail sync loads ALL emails into memory.** For 500k emails, this means no checkpoints, OOM risk, ~28h runtime with zero failure tolerance. The fix: a resumable month-by-month driver (`full_index_chunked.py`) that commits each month durably. This was later superseded by E10's Cloudflare pipeline.

3. **The `--clear` flag triggers an interactive y/n prompt.** Can't be used in detached background processes. Workaround: wipe the ChromaDB collection directly, then launch without `--clear`.

4. **Windows console Unicode bug in `rich` library.** Python's `smail` CLI crashes trying to print emoji checkmarks. Fix: set `PYTHONUTF8=1 PYTHONIOENCODING=utf-8` in the environment. Also, the `smail search` CLI has an interactive prompt that must be bypassed with `printf 'n\n' | smail search ...`.
